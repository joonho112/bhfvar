# Articles

### Getting Started

- [bhfvar: Bayesian Hybrid Framework for Variance
  Decomposition](https://joonho112.github.io/bhfvar/articles/introduction.md):

  An introduction to the bhfvar package for Bayesian variance
  decomposition in complex surveys with post-hoc domains, addressing
  informative sampling and finite-sample variance inflation.

- [Quick Start: Your First Variance Decomposition in 5
  Minutes](https://joonho112.github.io/bhfvar/articles/quick-start.md):

  Learn how to perform your first Bayesian variance decomposition with
  bhfvar in just 5 minutes using the included synthetic data.

### Applied Guide

- [Model Diagnostics and Convergence
  Checking](https://joonho112.github.io/bhfvar/articles/diagnostics.md):

  A comprehensive guide to assessing model convergence, diagnosing
  problems, and validating results from bhfvar models.

### Methodology

- [Methodology: The Bayesian Hybrid
  Framework](https://joonho112.github.io/bhfvar/articles/methodology.md):

  A detailed treatment of the Bayesian Hybrid Framework for variance
  decomposition, including the statistical model, pseudo-likelihood, and
  de-attenuation procedures.

- [Understanding the Dual Estimand Framework: A, B, and
  A\*](https://joonho112.github.io/bhfvar/articles/dual-estimands.md):

  A detailed guide to the three variance decomposition estimands in
  bhfvar: Policy (A), Descriptive (B), and Policy Adjusted (A\*), with
  guidance on which to use for different research questions.

### Reference

- [API Reference: Complete Function
  Documentation](https://joonho112.github.io/bhfvar/articles/api-reference.md):

  Comprehensive documentation of all exported functions in the bhfvar
  package, with detailed parameter descriptions and usage examples.
